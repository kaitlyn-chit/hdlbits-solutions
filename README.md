# HDLBits-Solutions

Verilog/SystemVerilog solutions to the HDLBits problem set, worked through as part of my prep for hardware engineering internships (targeting RTL/digital design roles).

## About

This repo tracks my progress through HDLBits — a browser-based platform for practicing Verilog/SystemVerilog. Each folder corresponds to a section of the problem set, moving from basic syntax up through sequential logic and finite state machines. Each file is named after its corresponding HDLBits problem for easy reference.

## Progress

- [x] Verilog Basics
- [x] Vectors
- [x] Combinational Logic
- [ ] Sequential Logic — *in progress (Shift Registers)*
- [ ] Finite State Machines
- [ ] Building Larger Circuits

## Simulation

Solutions are simulated using [EDA Playground](https://edaplayground.com) (free, browser-based, no install required).

## Why this repo

Solving digital design problems in Verilog mirrors real RTL design workflows used at chip companies. This repo is both a learning log and a portfolio piece showing hands-on hardware description language experience.
